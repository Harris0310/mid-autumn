# 中秋 · 镂空跳动爱心

一个纯静态的中秋祝福页面：**可以转着看的 3D 镂空跳动爱心** + **自下而上流动的字**。
无构建、无依赖，双击 `index.html` 即可运行。

## 运行

```bash
# 方式一：直接打开
start index.html

# 方式二：起个本地服务（推荐，避免个别浏览器对本地文件的限制）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

调试用：网址后加 `?t=1.2` 可把画面冻结在第 1.2 秒，方便截图核对。

## 3D 与视角

爱心是一颗**真正立体的、中空的心**：每个粒子在 2D 轮廓的基础上还带一个 z，
半厚度 `T(s) = thickness · √(1 − s²)` —— 中心最厚、到轮廓收到 0。所以正面看
仍是原来那颗镂空的心，转起来才看得出是一颗有厚度的心形。

**用手指或鼠标拖动**即可转动：

| 操作 | 效果 |
| --- | --- |
| 上下拖 | 俯仰（上下视角），限位 ±66° |
| 左右拖 | 偏航（左右视角），限位 ±83° |
| 松手 | 带惯性继续转一会儿再停 |
| 静止 1.5 秒后 | 自己缓慢左右摆动，暗示这是立体的 |

手感反了的话，把 `js/config.js` 里 `orbit.invertPitch` / `orbit.invertYaw`
改成 `true` 即可。手机上拖动不会触发页面下拉刷新（`touch-action: none`）。

## 改文案

**只需要改 `js/config.js` 里的 `text.scroll.pool`**，那是一组句子，
页面会一行一行自下而上滚动，每滚完一行就从池子里随机再抽一句。

每一行出现的位置取自上一行下方一个**随机**间距（`gapMinRatio`~`gapMaxRatio`
倍字号），所以屏幕上的疏密和出现时间都是不规律的；但所有行速度完全一致，
相对间距一旦定下就永不改变 —— 不规律会一路保持到顶，也绝不会互相追上或重叠。

```js
pool: ['但愿人长久', '千里共婵娟', /* ... */],
```

> 建议每句字数尽量接近。字号与行距是固定的，句子长度一致时屏上的文字量
> 才恒定，节奏看起来才均匀。

同文件里还可以调（都有中文注释）：

| 位置 | 作用 |
| --- | --- |
| `text.scroll.size` / `minViewportRatio` / `maxSize` | 字号及其上下限（保证手机上不缩成小字） |
| `text.scroll.gapMinRatio` / `gapMaxRatio` | 行距的随机区间（字号 × 该值），越大越不规律 |
| `text.scroll.speedRatio` | 上升速度 = 字号 × 该值（所有行一致，调快就调大） |
| `text.scroll.color / highlight` | 粉色底色与流光高光 |
| `heart.beat.mode` | `'classic'` 原版匀强正弦 / `'pulse'` 仿真双脉冲 |
| `heart.beat.period` / `amplitude` | 搏动周期与幅度（原版 1.2566s、0.05，想更猛就调大） |
| `heart.beat.jitter` | 逐点抖动强度，设 0 关闭以省性能 |
| `heart.enlarge` / `layers` / `profile` | 爱心大小、粒子密度、镂空程度与配色 |
| `heart.cx` / `cy` | 爱心在设计画布中的位置 |
| `heart.depth.thickness` | 3D 半厚度：调大更"胖"，0 就退回平面 |
| `heart.depth.perspective` | 透视焦距，调小透视更夸张 |
| `heart.depth.bands` / `backAlpha` | 深度分档数与背面暗度（前后层次） |
| `orbit.enabled` | 关掉就完全不响应拖动 |
| `orbit.*Sensitivity` / `maxPitch` / `maxYaw` | 转动灵敏度与限位 |
| `orbit.inertia` | 惯性衰减，越接近 1 转得越久 |
| `ambient.*` | 背景星点与金色微尘 |
| `seed` | 随机种子，换一个就是另一颗心 |

## 文件结构

```
index.html          页面外壳
css/style.css       全屏夜色背景
js/config.js        ★ 唯一配置入口（文案在这里）
js/heart.js         镂空跳动爱心：粒子引擎 + 双脉冲心跳
js/flowtext.js      流动的字：固定槽位的自下而上字幕
js/ambient.js       背景星点与微尘
js/main.js          启动、视口适配、主循环
_dev/preview.js     开发辅助：离线把画面渲染成 PNG（无需浏览器）
```

> `_dev/preview.js` 只用 Node 内置模块（vm / zlib）加载真实的 `heart.js`，
> 配一个迷你 Canvas2D 把粒子光栅化成 `_dev/heart_preview.png`，
> 改完爱心参数后可以直接核对形状与密度分布：`node _dev/preview.js`

## 实现要点

- **配色以中国红为主体**（对齐 `heart.cpp` 的 `RGB(255,33,33)`）。
  注意这**不是** `heart_particle.cpp` 里那套深红 —— 那套（主体 R 只有 76~152）
  是从一张暗调参考图实测的，放到纯黑背景上会发灰发闷，看不出原版那种
  "亮红实心"的劲儿。
- **镂空**：粒子按「径向密度剖面」布点 —— 中心极稀、约七成半径处最浓、
  最外圈转淡，再叠一层沿轮廓法线抖动的毛边和一层空腔雾点。
- **密度归一化**用「自形心的射线归一化」`s = |p−形心| / R(θ)`，
  保证等密度线严格贴合心形，顶部裂口与底部心尖不会被压歪。
- **3D 完全在 JS 里逐点算**：按心跳放大 → 绕 Y 轴（左右）→ 绕 X 轴（上下）
  → 透视除法。粒子按深度分成 `bands` 档、**由远及近**绘制，最远一档压低
  透明度，于是前后有层次、近处粒子自然盖住远处。没有用 WebGL，也没有
  引入任何 3D 库。
- **空腔雾点只铺在厚度中间薄薄一层**（`depth.hazeSpread`）：铺满整个厚度的话，
  一转起来正面与背面重叠，会把"镂空"糊成实心。
- **心跳**用回原版 `heart.cpp` 的匀强正弦 `ratio = 15·sin(frame·0.1)`：
  ω = 5 rad/s、周期 2π/5 ≈ 1.26 秒，正负对称、中间不停顿，等幅一下一下
  很实 —— 不写实，但浪漫。原版的力场位移 `|d| = ratio / r^0.04` 在
  整个半径范围内几乎是常数，等价于约 ±5% 的等比缩放，所以这里直接用一个
  缩放矩阵表达。
- **逐点抖动** `rand()%3-1`（`heart.beat.jitter`）：原版每帧给每个点加
  随机偏移，整颗心持续"沸腾"，搏动时才不像一张放大的静态图 —— 这是力量感
  的一部分。设为 0 可回到"坐标全静态、每帧只改一个缩放矩阵"的零开销路径。
- **另一个节奏** `heart.beat.mode = 'pulse'` 保留着仿真心音的双脉冲
  （强搏动 + 弱搏动 + 舒张期），更写实但力量感弱，随时可切。
- **字幕版式**：每行落点取自上一行下方的**随机**间距，所以疏密与出现时间都不规律；
  但所有行速度完全一致，相对间距永不改变 —— 不规律能一路保持到顶，
  又绝不会互相追上或重叠。

## 手机上如果觉得卡

页面是为手机分享做的，性能上有三个可以立刻调松的旋钮（都在 `js/config.js`）：

| 旋钮 | 做法 |
| --- | --- |
| `heart.beat.jitter` | 设为 `0`，省掉每帧 8649 次随机抖动的路径重建 |
| `heart.depth.bands` | 从 3 降到 2，`fill()` 调用次数直接少三分之一 |
| `heart.layers` | 三个粒子层数量各减三到四成（观感几乎不变） |
